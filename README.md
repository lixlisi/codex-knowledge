# codex-knowledge

个人 Codex 工作经验库。主力机器负责维护，其他机器通过私有 Git 仓库拉取。这里保存可复用的规则、步骤和经过验证的经验；项目专属约定仍放在对应项目仓库。

## 内容

- `global/AGENTS.md`：个人通用规则，取自当前主力机器的全局规则。
- `playbooks/`：跨项目可复用的操作步骤。
- `templates/`：新项目或交接时可复制的模板。
- `notes/`：经过验证的经验记录。新增经验时写明适用范围、证据和复查日期。

## 在另一台机器使用

1. 远端私有仓库创建并推送后，克隆到另一台机器。
2. 阅读 `global/AGENTS.md`，与另一台机器现有的 `~/.codex/AGENTS.md` 比较，再手动合并；不要直接覆盖已有规则。在 Windows 上，默认位置通常是 `%USERPROFILE%\.codex\AGENTS.md`。
3. 将项目专属规则放进该项目的 `AGENTS.md`；把相关经验文档放进项目 `docs/` 或在项目规则中注明何时查阅本仓库中的文档。
4. 在新任务中询问 Codex“当前加载了哪些指令文件”，确认规则生效。

全局 `AGENTS.md` 不会因为 Git 仓库更新而自动安装到另一台机器。此仓库中的 `global/AGENTS.md` 是共享原稿；两台机器各自的实际全局文件需要同步或合并。

## 维护原则

- 只记录已经发生且可验证的经验；假设和待验证方案明确标记。
- 避免在通用规则中堆积某个项目的临时状态。
- 不提交密码、令牌、Cookie、私钥、含个人数据的日志或本机认证缓存。
- 修改规则后，在另一台机器启动新任务检查加载结果。
