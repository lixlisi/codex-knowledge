# 任务工具清单与实际可用性

- 适用范围：Codex 桌面应用的跨任务协作能力检查。
- 现象：工具清单中可能出现 `list_threads` 等任务工具的说明，但实际调用时返回接口已迁移的错误。
- 验证过的处理方法：在设计跨任务流程前，先对目标会话执行一次只读的任务列表调用；只有调用成功并返回任务 ID，才依赖相关通信工具。
- 不适用或有风险的情况：这是特定桌面会话的观察，不能推断所有版本或机器均不支持任务间通信。
- 证据：本会话于 2026-09-09 调用 `list_threads(limit: 10)` 时收到“旧动态工具已停用，改用 codex_app MCP”的错误；当时没有可用的新任务列表接口。
- 最后复查日期：2026-09-29。
